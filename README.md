# أطوار (اسم مؤقت)

تطبيق لرصد تطور العلوم عبر نصوص كتبها: تُدخل نص المسألة من كل كتاب، فيقارنه بما سبقه زمنياً، ويصنف العلاقة (نقل بالنص، زيادة قيد، اختصار…)، ويستخرج نسب الكتب وعائلاتها المعرفية.

## التشغيل

```bash
npm install
npm run dev      # خادم التطوير على http://localhost:5173
npm test         # اختبارات محرك المقارنة
npm run build    # نسخة للنشر في مجلد dist
```

## البنية

- `src/engine/` محرك المقارنة: توحيد الرسم، والمحاذاة، والتصنيف، وتحليل النسب. لا يعتمد على أي خدمة خارجية.
- `src/data/` الحفظ على الجهاز (IndexedDB)، والعينة التجريبية، والنسخ الاحتياطي.
- `src/screens/` الشاشات، و`src/ui/` المكونات المشتركة.

البيانات تُحفظ على الجهاز وتعمل بلا إنترنت، والتطبيق قابل للتثبيت على الشاشة الرئيسية. المزامنة بين الأجهزة، وتصوير الصفحات، وقياس التشابه في المعنى مراحل قادمة.
